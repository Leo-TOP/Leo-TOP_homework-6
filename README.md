# ДЗ 6. API-витрина: музыкальные исполнители

Небольшое приложение-витрина, которое получает коллекцию музыкальных исполнителей из собственного REST API, показывает её и позволяет добавлять новые записи через форму.

## Тема

API-витрина музыкальных исполнителей: список групп и артистов с описанием, жанрами, изображением, годом основания и статусом активности. Данные хранятся в `json-server` и сохраняются в `backend/db.json`.

## Endpoint

http://localhost:3000/artists

## Модель данных

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Генерируется сервером (`json-server`) при создании записи |
| `name` | string | Название исполнителя |
| `description` | string | Краткое описание |
| `genres` | string[] | Массив жанров |
| `imageUrl` | string | URL изображения |
| `formedYear` | number | Год основания |
| `isActive` | boolean | Активен ли исполнитель |

## Запуск

Понадобятся Node.js `22.12` или новее, npm и VS Code с расширением Live Server.

**Backend:**

```bash
cd backend
npm ci
npm run dev
```
